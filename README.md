# oneshot-zap

X(Twitter) の各ポストに⚡ボタンを足し、**1クリックで「スパム報告 → ブロック」**を実行する Chrome 拡張。

参考の「ワンクリックブロック」系がブロックのみなのに対し、本拡張は**実際の報告フローを自動操作して
スパム報告までやってからブロック**する。

> ⚠️ **本物のスパムにのみ使うこと。** 確認ダイアログ無しで即実行し、取り消しはできない。
> まず捨て垢などで挙動を確認してから使うこと。日本語 UI 前提（表示言語が日本語のときのみ動作）。

## セットアップ

```sh
pnpm install
pnpm run dist     # dist/ を生成
```

`chrome://extensions` → デベロッパーモード ON → 「パッケージ化されていない拡張機能を読み込む」→
生成された **`dist/`** を選択（repo 直下ではない。`dist/` がそのまま拡張ルート）。

## 使い方

x.com を開くと各ポストのアクションバー右端に⚡が出る。押すと自動で
`… → ポストを報告 → スパム → 次へ → ブロック → 完了` まで進む。結果はトーストで表示。

初期状態では実行前に確認モーダルが出る。`chrome://extensions` → oneshot-zap の「詳細」→
「拡張機能のオプション」で **確認のオン/オフを切り替えられる**（OFF にすると 1 クリック即実行）。

## 開発

```sh
pnpm run test:run   # 単体テスト(vitest + happy-dom)
pnpm run typecheck
```

X の DOM 変更で `src/flow.ts` のセレクタが壊れたら、捨て垢で実フローを 1 度なぞって
各ステップのセレクタ（caret / report / "スパム" / Next / "さんをブロック" / 完了）を更新する。
